# 图形工作台使用流程

## 1. 工作区与案件

- 首次启动优先使用 `Documents\JianYin Cases`。
- 如果当前进程无法写入该目录（例如 Windows 受控文件夹访问限制），自动退到项目同级的 `JianYin Cases`。
- “选择工作区”可切换到任意本地目录；每个工作区自带 `workspace.json`。
- 案件按 UUID 存放，案件名只作显示，不参与路径。

## 2. 导入

支持 TXT、Markdown、DOCX、文本 PDF、扫描 PDF。

- 扫描 PDF 自动调用本地 `pdf-to-markdown`，底部显示页进度。
- 同一密码的多个 PDF 使用“批量解锁 PDF”；密码只在内存中使用。
- 加密 PDF 的原始加密副本保留在 `sources/`，供识别的解锁副本也在本地。
- 重复文件会提示“与已导入文档内容相同”，但允许继续导入。

## 3. 分析

点击“分析敏感信息”：

1. 加载 Q4 ONNX 模型（首次可能下载约 945 MB）；
2. 按窗口推理，整篇做一次 Viterbi 解码；
3. 运行中文补强规则；
4. 生成规则草稿并保存在 `rules/draft-rules.json`。

已有草稿时会询问：

- **是**：保留手工规则和已编辑替换值；
- **否**：全部重新生成；
- **取消**：不分析。

分析可取消；取消不会覆盖旧草稿。

## 4. 规则清单

- 列：启用、类别、原文、替换为、命中/字面、来源、备注。
- 双击或“编辑”修改类别、替换值、匹配方式、备注、启用/停用。
- “添加规则”：
  - 可先在原文中选中一段文本，再点按钮；
  - 也可在对话框中手动输入原文；
  - 替换值留空会在应用前自动生成。
- “启停”切换是否应用。
- “重置替换值”按当前策略重新生成，不保留人工修改。
- 过滤框可按类别、原文、来源、备注筛选。

规则来源：

- 模型：`模型`；
- 中文补强：`中文规则·身份证号` 等；
- 手工：`手工`；
- 组合：显示为 `模型 + 中文规则·姓名线索`。

## 5. 应用脱敏

点击“应用脱敏”：

- 先计算全部文档，再写入，失败不写部分结果；
- 写入 `outputs/redacted/<id>.md`；
- 设置中开启 DOCX 时同时写 `.docx`；
- 写入 `rules/case-redaction.json`；
- 覆盖旧映射前归档到 `rules/archive/`。

应用后右侧“脱敏页”显示结果；原文页保留高亮，便于对照。

## 6. 导出

“导出”可选择：

- 当前文档 / 当前案件全部文档；
- Markdown、DOCX；
- 是否同时导出映射 JSON（含原始值，谨慎外发）。

导出文件名使用显示名 + `-脱敏`，冲突自动追加编号。

## 7. 还原

“还原”使用最新映射：

- 逐处校验脱敏文本偏移；
- 任一处被手工修改则整次拒绝；
- 全部通过后写 `outputs/restored/`；
- 原始文件不会被修改。

## 8. 状态

- 已导入：有提取文本；
- 已分析：有规则草稿；
- 已脱敏：有映射和脱敏输出；
- 已还原：有还原输出；
- 规则已修改，待重新应用：草稿 hash 与映射不一致。

## 9. 设置

- 模型目录；
- 策略规则 JSON；
- 中文补强逐项开关；
- 推理窗口/重叠；
- Viterbi/argmax；
- 是否生成 DOCX。

模型、规则或中文开关变化后，请重新分析；只改替换值则直接重新应用即可。
